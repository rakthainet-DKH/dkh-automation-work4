## Overview

DKH Automation Work 4 is a comprehensive automation platform built with Java and Go microservices.

## Key Features

### Workflow Automation
- Automated workflow execution
- Manual configuration support
- External workflow integration
- Real-time monitoring

### Management
- Single-person management
- Role-based access control
- Activity logging
- Dashboard

### Security
- JWT authentication
- RBAC
- Encrypted storage
- Audit logging

## Technology Stack

- Java (Spring Boot 3.x)
- Go (Gin/Echo)
- Kubernetes & Docker
- PostgreSQL & MongoDB
- GitHub Actions
